# Airline Loyalty Intelligence Dashboard

## Overview

This project analyzes airline loyalty program data to identify customers at risk of disengagement and provide actionable retention recommendations. The solution combines customer segmentation, churn prediction, and executive-focused analytics within an interactive dashboard designed for non-technical business users.

## Objectives

Identify customers requiring immediate retention attention.
Quantify potential revenue at risk.
Segment customers based on value and engagement.
Translate analytical outputs into actionable business recommendations.

## Methodology

### Data Sources

Customer Loyalty History
Customer Flight Activity
Calendar Data

### Feature Engineering

Key features include:

Customer Tenure
Engagement Score
Total Flights
Total Distance Traveled
Points Earned and Redeemed
Inactive Months
Average Flights per Month
Redemption Behavior Metrics

### Customer Segmentation

Customers are categorized into:

Loyal High Value
Stable
At-Risk Premium
Disengaged

### Churn Analysis

A machine learning classification model was developed to identify customers exhibiting churn risk characteristics. Model outputs are translated into business-focused retention actions through the dashboard interface.
